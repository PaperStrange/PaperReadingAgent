# Sprint 5（2026-08-30）—— 实战问题修复（目录生效/检索说明/UI/回调上限/SSE 断连）

> 归属：`docs/iteration/sprint/`。输入：用户实战截图与 5 项问题。roadmap C/E3 继续 hold。

## 1. Sprint Planning

- **Goal**：修复 5 个实战问题并使"改配置→改目录→重跑"闭环自洽；UI 增加报错复制与步骤计时；检索选择逻辑透明化；litellm 回调上限防崩溃；SSE 断连静默。
- **勘察结论**：
  1. 改目录后 load_index/parse 用旧配置：**前端节点参数独立**——load_index 用上次 config 的 session.settings，面板改参后未自动重跑 config（节点已标 stale）；parse 报"no such file"是旧索引文件 + 新目录组合。
  2. retrieve top_n：Tantivy BM25 chunk 级排名；**零命中时回退取索引前 N 个文件**（用户所见"与 query 无关"）；候选可能含重复 chunk 路径。
  3. UI：面板标题 `.node-block-title` 左 padding(6px) 与行内容(8px) 不齐；error 不可复制；Function Subcanvas 无步骤计时。
  4. MAX_CALLBACKS：litellm 每次 Router 实例化注册 logger（paperqa 每次模型创建），累积至 30 上限报错。
  5. SSE：客户端断连后 send 抛错由 uvicorn 记录（仅噪音，但应静默）。
