## 1. Sprint Planning

- **Goal**：搭建独立轻量看板 `agents-dashboard/`（Next.js App Router + Tailwind + shadcn/ui + better-sqlite3/Drizzle/FTS5 + chokidar），端口 8600；文件为真相源（`agents/runtime/registry.json` + `agents/runs/` 报告 + `agents/functions/*.md`）、SQLite 为派生只读索引；六页面支持 spec 编辑、skill URL 配置、runtime 状态/自报上下文/估算消费展示、memory 报告浏览；以本轮真实账本（5 条 run：3 三查 + 2 impact 验证）为验收数据。
- **团队与产能**：1 人（AI 开发者），预估 **12 点 / ~12h**。
- **周期（时间盒，必填）**：**2026-08-31 ~ 2026-09-01（2 个工作日）**；超时预案：与用户确认后砍"图表页"或"报告浏览页"范围（三选一：续期/拆卡/砍范围）。
- **验收演示**：一次真实 fan-out（账本登记）→ 看板完整呈现 状态/自报上下文/估算成本/报告浏览 + spec 在线编辑生效。
