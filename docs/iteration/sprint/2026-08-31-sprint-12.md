## 1. Sprint Planning

- **Goal**：① 全字段交互表单——按 schema 类型渲染控件（string/password/number/integer/boolean/enum/string_list）、分组/中文标签、readonly 禁改展示；② 字段级校验——POST /api/config/validate 联动（防抖），errors/warnings/hints 渲染到表单；③ impacts 影响提示**切换前可见**（字段下方常驻）；④ provider 联动并入（下拉选 provider → 自动带出 api_base/model/vision/embedding；无 embedding API 则删除 embedding_model 交后端自动选择）。
- **团队与产能**：1 人（AI 开发者），预估 **6 点 / ~6h**。
- **周期（时间盒，必填）**：**2026-08-31（网络时间 UTC+8，1 个工作日）**；超时预案：与用户确认后把 US-12.2 的防抖/错误渲染细化推到 Sprint-13（三选一）。
- **验收演示**：Config 节点全字段表单截图（含 impacts 提示与字段级错误）；provider 联动实测（openrouter 带出 / deepseek 删除 embedding）；gui_check_s4/remote 更新后 PASS；verify_config_schema 104 断言仍绿。
