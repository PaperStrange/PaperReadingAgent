## 1. Sprint Planning

- **Goal**：阶段 A——把已冻结的 SSOT（config_schema.py）**暴露为 API 并接入前端**：① 后端新增 `/api/config_schema`（GET）与 `/api/config/validate`（POST）② 前端 Config 节点从 API 拉取 schema、以分组字段清单（只读）渲染并保留现状手写面板，③ **M7 收敛**：App.jsx 配置默认值对象与 SSOT 默认值逐项比对，重复处改为引用/校验锁定。
- **团队与产能**：1 人（AI 开发者），预估 **5 点 / ~5h**。
- **周期（时间盒，必填）**：**2026-08-31（网络时间 UTC+8，1 个工作日）**；超时预案：与用户确认后把 US-11.3 推到 Sprint-12（三选一：续期/拆卡/砍范围）。
- **验收演示**：后端启动后 `GET /api/config_schema` 返回 7 分组完整 schema（JSON）；`POST /api/config/validate` 对非法值返回字段级 errors；前端 Config 节点展示分组字段清单截图；`verify_config_schema.py` 全 PASS。
