## 交付与实测（2026-09-25，Sprint-17 D3｜主代理实现 + 本卡自证）

**① 测量口径（唯一真源 = `agents/policy.json::ledger_measurement`，本卡不再复述第二份）**

| 口径 | 结论 | 落点 |
|---|---|---|
| `dur` | **墙钟**：`ended_at - started_at`（同 run **累计**；`round` 追加会前移到末轮）。**不是**"首末轮差值"——账本逐轮只有 `ended_at`、没有逐轮 `started_at`，两者在现有结构下不可区分；**不是**报告自报时长（报告时长不得回填账本） | `agents/policy.json` 键 `ledger_measurement.dur`；`verify/verify_ledger_measurement.py` 模块 docstring；`scripts/agent-ops.py::measurement_of()` docstring |
| `rounds` | **真源 = 报告轮次**：能数出 `Round N`/`第 N 轮` 时以报告为准并与账本 `rounds_count` 核对；报告不可数时账本值只是 `declared` 声明，**不得当实测值上报看板** | `ledger_measurement.rounds` + `report_round_pattern` |
| 缺值 | **必须显式 `unknown`**：`dur_minutes=null` + `measurement_source=unknown`，`list` 打印 `dur=unknown`；**禁止**用 `0.00`/整十分钟退化值冒充（`0.00` = 未测得，不是零耗时） | `ledger_measurement.unknown` + `measurement_sources` |
