## 仍未闭环（本批**不**声称已闭环；诚实标注）

1. **C3 未归属提交（真数据 15~30 条，随锚点取值）**——结构性原因：内容评审类 run 的 `covers_through` **都早于 HEAD**（最新一条 = `code-review-067` 的 `4f2fcc1551`），而锚点之后必须"每个提交都有归属"。以锚点 `092a2f78` 实测：58 提交 / **30 UNOWNED**；以 `9ffc108d` 实测：28 提交 / **15 UNOWNED**；以 `08dbea94` 实测：9 提交 / **6 UNOWNED**。B1~B4 **不消除**这一类（B1 只收窄"窗口起点"口径，不扩大任何 run 的覆盖宽度）。
