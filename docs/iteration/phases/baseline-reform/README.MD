## 2. 阶段目标（一句话）

把"基线"从**只防恶化的棘轮**改造成**必须自证性价比的仪器**：每一条上限／基线／阈值都要能回答三问——**谁是它的消费者、它最近挡住过哪一条真实缺陷、它最近造成了多少返工**；答不出的按裁定删除或改造。

| 对象 | 关系 | 不在本阶段做的事 |

## 4. 口径纪律（本阶段自带，四条）

1. **读数三件套**：每条基线必须给「**消费者**（哪个闸门读它）｜**当前读数**（现跑命令 ＋ 输出）｜**最近一次实际挡住的真实缺陷**」；给不出第三项的，写「**无留痕案例**」，**不得**用推测补。
2. **时点锚**：写死的读数一律**同行带时点锚**（日期或 sha）；当期主张一律写成"命令 ＋ 以该命令输出为准"（`docs/1-WORKFLOW.MD` §6 规则 2「派生数字不得手抄」）。
3. **机检性声明的真源**：本节所有"有执行点／仅文字"的分级，引用 `docs/1-WORKFLOW.MD` §6.0 机制索引，**不复制、不改写**它。
4. **不拿判据换绿**：本阶段任何处置（保留／改造／删除）都不得通过放宽判据或上调上限来实现；允许的方向只有"按当次实测**下调** cap"与"删除**无消费者**的基线"。
