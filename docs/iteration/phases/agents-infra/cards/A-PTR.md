## 正文
`docs/6-DECISIONS.md` 的 V- 条目用 `path:line` 指向规范文档；`verify_decision_register.py` 能抓漂移（逐字引文须落在指针 ±2 行内），但**每次向 `docs/**` 插入内容都要重新同步**，2026-09-29 一天撞 4 次。

**方向**：指针改为**稳定锚点**（小节标题文本／规则号／符号名），行号降级为提示；判据仍须能定位到唯一位置。

**验收**：向被引用文档中部插入 5 行后，登记册闸门在**不改任何指针**的前提下仍 `ALL PASS`。

## 设计

### 语法

```
path#<锚文本>            # 指向锚点所在行
path#<锚文本>+N          # 指向锚点行往后第 N 行（N 带符号；默认 0）
```

- `<` `>` 是**语法的一部分**（定界符），不是占位符：它让指针在散文、表格与 shell 参数里
  自带左右边界，不必靠反引号包住，也不必约定"锚文本不许含空格"这类隐式规则。
- **锚文本两选一**：① **标题行**（`#` 之后那一串）；② **唯一行首片段**——取该行开头那串
  可读文字。片段要"人在文档里一眼能找到"，不写行号、不写偏移。
- 规范化（两侧同一套，`scripts/anchor-resolve.py::norm`）：去 `**`、去反引号、去全部空白
  （含 U+3000）、去行首 `>` 引用符、去列表序号（`1.` / `-` / `*` / `+`）。
- 命中规则：标题文本**以锚文本开头**，或该行正文**以锚文本开头**（前缀而非精确等）。
  前缀让锚文本能写短，唯一性由下一节兜住——**短锚不是放宽，是让人愿意写**。
- 围栏（```` ``` ```` / `~~~`）内**不是锚点域**（与登记册判据 8 同口径）：示例代码里的同名行
  不参与匹配；行号按**物理行**算，不漂。
- 禁止：锚文本含 `<` `>`；路径含 `#`；绝对路径与 `..`（解析器一律 fail-closed）。
- 登记册里的锚文本**不得出现"冒号紧跟数字"**：`path:line` 的扫描器只认"路径 + 冒号 +
  数字"，`#<…:12>` 会被它当成一条行号指针重复计数（试点 5 条都不含该形态）。

### 唯一性要求

- 命中数**必须恰好 1**。前缀匹配天然可能多命中，故唯一性是**判据**不是约定。
- 唯一性是**同文件内**的唯一：不同文件各算各的，不要求锚文本全局唯一。
- 锚到标题时，该标题须能唯一定位到那一节；同一文件出现第二个同前缀标题即退化为
  多命中 ⇒ 必须加限定语或改用该行的行首片段。

### 歧义处理（fail-closed，点名）

- **0 命中** ⇒ rc=1，输出"0 命中：`<文件>` 里没有以锚文本开头的标题或行"，并提示
  锚文本写错 / 段落已被改写或删除。**不得**当成"未核"放行。
- **多命中** ⇒ rc=1，输出"`N` 处命中（多义 ⇒ fail-closed，必须收窄锚文本）"，并把
  候选的**行号 + 首行摘要**逐条点名（前 6 个，其余给"另有 N 处"）。
- 闸门侧同口径：`verify_decision_register.py` 把解析失败的锚点记成
  `[指针·锚点] … 无法解析（<status>）` 的 **problem**（不是 WARN、不是 SKIP），计进
  `bad_pointers`，与 `path:line` 坏的三种形态（被删 / 打错改名 / 越界）同级。

### 指向"某段的第 N 行"

- 形态 = `path#<锚文本>+N`。语义是"锚点行的第 N 行相对位置"，默认 0。
- **有代价**：`+N` 把段内相对位置重新绑进行号——插入点若落在**锚点与目标行之间**，
  仍会漂。故它只用于"引文紧邻标题、段内结构固定"的场景，且 N 越小越好。
- 能直接锚到目标行的行首片段时**一律不用** `+N`（试点 5 处里只有 1 处用了 `+2`）。

### 与旧 `path:line` 的共存期策略

- **两形态并存，判据同一条**：`verify_decision_register.py` 把两种形态送进**同一条**
  "路径存在 / 行号在范围内 / ±2 引文窗口"代码路径；`pointers` 计数**按条数**计，不按
  形态计（试点前后同值）。旧的 `path:line` 一个都没有删、也没有收紧。
- **不迁移、不批量替换**：存量 `path:line` 全部继续有效；新写的指针**优先锚点**。
  一次只改**被实测漂过**或**正在改动**的条目，改一处核一处。
- **不放宽**：不因为"锚点更稳"就放宽 ±2 窗口、不减少断言；锚点解析失败是 **FAIL**，
  不许"降级成行号"兜底。
- **退出条件**（未来）：当旧形态的漂移读数长期为 0、且锚点覆盖率足够时，才讨论是否
  收紧；在此之前旧形态是**合法形态**，不是技术债。

### 风险（迁移时逐条要挡）

- **锚文本被改写即 0 命中**：这是**想要的**响亮失败（比静默漂移好），但迁移期会成批红
  ⇒ 必须逐批小步、每批带解析器自检，不许一次性大替换。
- **唯一性**：`字`/`规则` 这类短锚极易多命中；批处理脚本须**先解析再写盘**，多命中即整批
  回退（对应规则 422"自动化改写脚本的纪律"：前置条件 ＋ 内容等价的独立判据）。
- **表格单元内的锚文本**：表格用 `|` 分隔，锚文本若含 `|` 会破表；`anchor-resolve.py`
  本身不管表格，写指针的人要避开。
- **`+N` 的段内漂移**：只允许"引文紧邻标题"的场景，且必须写注释说明为什么不用行首片段。
- **计数口径**：`pointers` 必须**按条数**而非按形态统计，否则"迁移"会伪造出计数下降
  （等于用读数漂移冒充改善）——试点已把这条钉成 1248 不变。
- **缺席分支**：`docs/iteration/**` 在 main 上不存在，锚点与行号一样只能记"未核"；
  锚点化**不减少**未核条数，别把 B3 当"降棘轮"的手段。
