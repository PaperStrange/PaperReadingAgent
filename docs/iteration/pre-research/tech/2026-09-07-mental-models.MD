# 预研笔记：思维模型管理（mental-models）

> 状态：**设计草案待确认，已开卡 M17**（2026-09-07）。本笔记是 M17 开工时 planning_pipeline 的强制上下文输入。
> 归属：`docs/iteration/pre-research/tech/`（仅 windows 分支维护）。

## 1. 背景与用户要求

用户（2026-09-07）：新增知识沉淀卡「**思维模型管理**」——把工程开发中总结的经验文档（3-LEARNED 等）转化成**更抽象的模型架构**。
- **成功判据**：模型能否**直接生成可执行的 agent workflow**（落到 AgentOps spec 体系上）。
- **规模**：若单卡容纳不下，按一个/多个 sprint 判断；视情况可当成**另一个工程项目**。
- **思维模型来源**：① 用户输入；② 我们的探讨交流；③ 由我主管**每次经验文档（3-LEARNED）更新时**提取候选模型。
- **初始思维模型（种子）**：「思维实验」（用户给出，字段见 §3）。

## 2. 设计草案（主代理方案，待确认）

### 2.1 模型 schema（统一字段）

| 字段 | 含义 |
|---|---|
| 名称 / 版本 | 唯一标识 + 语义化版本 |
| 模型描述 | 一句话：模型做什么 |
| 使用时机 | 触发规则（初始边界 + 自适应扩展条件） |
| 模型边界 | 不适用场景（负向定义，防止滥用） |
| 输入 / 输出 | 契约：输入材料 → 输出产物 |
| 创始人 | 思想溯源（人物/学派/来源） |
| 来源 | 用户输入 / 探讨交流 / 经验文档提取（含 3-LEARNED 条目号） |
| 成功判据 | 可实例化为可执行 agent workflow（validate-spec + 首跑演示） |
| 状态 | 草案 → 验证中 → 已固化 |

### 2.2 模型 → agent workflow 的生成机制

模型 schema 字段**一一映射**到 agent spec 五段式（`_template-agent.md`）：
描述→Role、使用时机→Trigger、输入→Task Input、模拟推演过程→Steps、输出比对文档→Output Template、边界→Forbidden、阈值→Configurable Parameters。生成器 = 模板实例化脚本；产物过 `validate-spec` + 首跑演示即"模型成功"。

### 2.3 库结构与规模判断

- 库目录草案：`docs/iteration/phases/mental-models/library/`（windows-only 迭代区；成熟模型可提升共享层）；
- **规模判断（主代理）**：① 模型 schema 与库结构 ② 模型→workflow 生成器 ③ 种子模型「思维实验」实例化+首跑 ④ 经验文档→候选模型提取 SOP（主代理主管，每次 3-LEARNED 更新时执行）⑤ 自适应触发扩展机制 ≈ **8~10 点**——单卡偏大，建议**按 2 段 sprint（M17 拆 M17-a/M17-b）或成立独立阶段 mental-models**（视用户意愿，用户提示"可当成另一个工程项目"）。

### 2.4 种子模型「思维实验」（用户给出 + 主代理补全 xxx 字段）

| 字段 | 内容 |
|---|---|
| 名称 / 版本 | 思维实验 / v0.1（草案） |
| 模型描述 | 对一个问题生成**不少于三种**解决方案，对每个方案解决过程进行**遵循客观规律事实的模拟**，输出方案预期效果并生成比对文档 |
| 使用时机 | **初始边界**：检测到用户输入讨论时启用；**扩展条件**：用户给予认可情绪反馈后，尝试覆盖到其他决策场景（每次扩展须记录并交用户确认） |
| 模型边界（主代理补全草案） | ① 不适用于已有既定决策基线的问题（基线不得重议，翻案建议除外——1-WORKFLOW §4.4）；② 不适用于纯事实查证（走 M16 调研分级机制）；③ 不适用于时间敏感需即时执行的任务；④ 模拟必须遵循客观规律事实，不得编造未经证实的作用机制 |
| 输入 | 一个问题/决策主题 + 上下文（预研笔记、约束条件、既定决策基线） |
| 输出 | 比对文档：≥3 个方案 ×（解决过程模拟推演、预期效果、风险与适用条件）+ 供用户裁决的建议排序 |
| 创始人 | 爱因斯坦（思想实验方法论的代表性实践者） |
| 来源 | 用户输入（2026-09-07） |
| 成功判据 | 实例化为 agent spec（如 `agents/functions/thought-experiment.md`）过 validate-spec + 首跑演示产出三方案比对文档 |
