# docs/iteration/archive/ —— 归档口径

**放什么**：被收敛批从**活文档**里移出的**叙述性内容**（历史过程记录、逐行处置表、对话纪要、
已完成批次的工程细节）。**逐字保留**，不重写、不压缩、不删句。

**不放什么**：① **机读判据**（阈值、状态码、棘轮、上限、判分逻辑）——必须留在活文档原位，
否则闸门失去可核对象；② 当前状态与未闭环项——留在活文档；③ `verify/**`、`scripts/**`、
`agents/runtime/**` 的产物。

**命名**：`<源档文件名去扩展名>-archived-<内容性质>.MD`。一个源档一个归档档；
段与段之间用 `---` 分隔，段首给 `<a id="...">` 锚点（供活文档一行指针跳转），段尾给源行区间。

**必须满足的三条**（缺一即视为破坏信息）：
1. **活文档每处移走都留一行指针**：`叙述已移入 \`<归档档>#<锚点>\``；
2. **归档内容逐字**：搬出前后对同一行区间取 `sha256`，两值必须相同（值写在归档档末尾的证明表里）；
3. **指针漂移为 0**：任何 `docs/**` 插入都会顶偏其他档指向本档的 `path:line` 指针 ⇒ 收敛批必须
   在改完后**重跑** `verify/verify_decision_register.py`，并核对 `pointers` 与 `quotes_drift` 两项
   **与改前同数**（只减不增）。
